\chapter{Дешифратор}

Двоичный код удобен, если нужно передавать или хранить данные, ведь для $16$ вариантов чисел
нужно всего $4$~бита или линии. Если же каждый из этих вариантов соответствует включению какой-либо цепи,
например, нужно зажигать $16$ разных лампочек, то при использовании двоичных чисел придётся
для каждой лампочки строить логическую схему, проверяющую, что передано нужное число.

Такую логическую схему удобнее делать не для каждой лампочки, а одну на всех. Входом схемы
будет двоичное число, а выходом --- $16$ линий, по одной на лампочку. Каждая линия
активируется для одного из вариантов входных данных. Например, линия $0$ активируется для числа $0000$,
а линия $9$ для числа $1001$. Такая схема называется дешифратором.

Дешифратор --- это устройство, на входе которого двоичный код, а на выходе
несколько сигналов, причём только один из них имеет значение <<истина>>.
Чаще всего дешифратор применяют так: он устанавливает единицу на выходе с номером,
соответствующим входному числу. К примеру, если на входе число $011$, то на выходе номер~$3$
будет единица, а на остальных ноль.

Дешифраторы могут иметь разную разрядность. В конструкторе есть модуль дешифратора
для двухбитных чисел. Соответственно он имеет $4$~выхода. Для удобства каждый из выходов
имеет шинный формирователь, поэтому при его активации сразу можно подключать
$4$ коммутируемых сигнала к соответствующему $4$-битному выходу.

Например, дешифратор может пригодиться, когда нужно выбрать один из регистров для выполнения
арифметических операций. Тогда мы могли бы сделать калькулятор, работающий с несколькими
операндами по выбору пользователя. А чтобы для выбора не пришлось задавать слишком много сигналов,
и нужен дешифратор.

Кроме входного числа (адрес), коммутируемой шины и выходных разъёмов,
модуль дешифратора имеет также дополнительный вход с сигналами, которые можно использовать для
его активации. К примеру, если перемычка {\tt Select} установлена напротив надписи {\tt +V},
то один из выходов будет активен всегда, в зависимости от значения адреса на входе.

Если же перемычку установить напротив одного из чисел, то дешифрация (и соответствующий выход)
будет активироваться только если на указанный вход выборки подана логическая единица.

\subsection{Устройство, угадывающее животных}

% a острые зубы
% b млекопитающее

% 0  пингвин
% 1  змея         a
% 2  жираф          b
% 3  леопард      a b

С помощью дешифратора можно реализовать простейший классификатор объектов по признакам.
Назовём это <<Устройство, угадывающее животных>>. Игрок (с помощью переключателей,
конечно же) должен ответить на вопросы
<<У него острые зубы?>> и <<Это млекопитающее?>>, а наше устройство зажжёт одну из лампочек (то есть включит
реле), каждая из которых отвечает за одно из животных. Для выбранных вопросов это будут пингвин, змея,
жираф и леопард.

% схема

Как это работает? Очень просто. Запишем в таблице выбранных животных и ответы на вопросы
в виде чисел $0$ и $1$, где $0$ означает <<нет>>, а $1$ --- <<да>>:

\begin{center}
\begin{tabular}{|c|c|c|}
\hline
 & У него острые зубы? & Это млекопитающее \\
\hline
Пингвин & 0 & 0 \\
\hline
Змея & 1 & 0 \\
\hline
Жираф & 0 & 1 \\
\hline
Леопард & 1 & 1 \\
\hline
\end{tabular}
\end{center}

Дешифратор устанавливает один выходной сигнал в единицу в зависимости от комбинации
единиц и нулей на входе. У выбранных нами животных все комбинации разные,
поэтому каждому из них можно сопоставить один выходной сигнал дешифратора.
