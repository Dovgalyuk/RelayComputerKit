\chapter{АЛУ}

Арифметико-логическое устройство (АЛУ) компьютера отвечает за вычисления.
В современных компьютерах АЛУ находится внутри микропроцессора.
Чтобы что-то посчитать, процессор должен подключить ко входам АЛУ операнды
(из регистров или, к примеру, из выполняемой команды). Результат затем помещается
ещё в какой-то регистр.

\section{Практикум}

\includegraphics[width=\columnwidth]{photo/calculator3.jpg}

Калькулятор с выбором операндов из регистрового файла.

Список модулей:
\begin{itemize}
    \item Модуль переключателей: \modulesswitches{6} штук
    \item Модуль унарных операций: \modulesunary{1} штука (или \modulesunary{2} штуки)
    \item Сумматор: \modulesadder{2} штуки
    \item Модуль логических операций: \modulesbinary{1} штука
    \item Дешифратор: \modulesdecoder{3} штуки
    \item Регистровый модуль: \modulesregister{4} штуки
    \item Кросс-модуль: \modulesmatrix{1} штука
    \item Модуль шины: \modulesbus{2} штуки
    \item Соединительный шлейф: \modulescable{18} штук
\end{itemize}
